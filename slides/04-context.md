# Файл «про меня»

<div class="text-lg opacity-85 mb-4">Пишется один раз. Работает во всех задачах.</div>

```md
# Про меня
- Город, часовой пояс, язык общения
- Семья: кто, возраст, что важно
- Ограничения: еда, здоровье, бюджет
- Как со мной разговаривать: коротко, без воды, без дисклеймеров
- Чего не делать: не советовать купить, не морализировать

# Как отвечать
- Сначала ответ, потом объяснение
- Если не знаешь — скажи прямо
```
